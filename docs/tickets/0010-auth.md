# 0010: Email + password sign-in and access tokens

## Goal
Real sign-in replaces the dev identity header.

## Scope
- Passwords hashed with `Bun.password` (argon2id). Sessions: random token in an httpOnly cookie, stored hashed in `Session`.
- `POST /auth/login`, `POST /auth/logout`, `GET /me`.
- Personal Access Tokens for the CLI: `POST/GET/DELETE /me/tokens`; token shown once; `Authorization: Bearer <token>`.
- Global guard: session cookie or PAT. The `x-vorasaan-user` header only works when `VORASAAN_DEV_AUTH=true` (tests, local seed).
- Org Role guard (`@AdminOnly()`).
- Web: `/login` page, sign-out, route protection; the dev switcher only shows with dev auth on.

## Acceptance criteria
- [x] Login success/failure, logout, expired session, revoked PAT (tests).
- [x] Without `VORASAAN_DEV_AUTH`, the dev header is ignored.
