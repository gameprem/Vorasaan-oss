Async checkout

Stop blocking checkout on the payment provider.

Goals

  • Checkout returns in under 2 s even when the provider is slow.
  • No double charge on retry.

Flow

  • Order is created as PENDING_PAYMENT.
  • A worker polls the provider every 5 s for up to 30 s.
  • The user is notified by push when payment settles.

Open questions

  • How long do we wait before treating a payment as failed?
  • Do we notify by push only, or also by email?

Decisions

  • Keep the cart for 30 minutes after a failed payment, so the user can retry.
